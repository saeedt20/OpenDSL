# Security reports

OpenDSL is a community modification of a legacy vendor firmware. A modern interface does not make its kernel, drivers or every bundled service current. A comprehensive vulnerability audit remains unfinished.

Restrict management access to a trusted local network. Do not expose the administration interface directly to the internet.

Report vulnerabilities privately through GitHub's private vulnerability-reporting interface when available. Do not post exploit credentials, private keys, configuration backups, serial numbers or live network identifiers in a public issue. If private reporting is unavailable, open a minimal issue requesting a private contact without including sensitive details.

For UI bugs, provide the OpenDSL version, model/revision, browser, viewport and reproduction steps with sanitized screenshots.

Only the current release is maintained. There is no guaranteed response time, unattended updater or proven automatic rollback system.
